# PulseBeam

PulseBeam is a collaborative monitoring platform built with Gleam and the BEAM ecosystem to track the availability and health of digital services, APIs, and endpoints.

The project is being developed incrementally with a software engineering-first approach: requirements, modeling, architecture, implementation, testing, and documentation.

## Product areas

- **PulseBeam Community** — public monitoring of relevant digital services.
- **My PulseBeam** — private monitoring of user-owned endpoints.
- **Monitoring Engine** — HTTP checks, latency, history, uptime, metrics, and future health scoring.

## Current status

The project is currently in the engineering and modeling phase. No production implementation has been added yet.
